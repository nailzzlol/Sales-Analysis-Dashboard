# Sales-Analysis-Dashboard
Developed an end-to-end data analysis project using Excel and Power BI to evaluate sales performance across different regions and product categories. The project involved data cleaning, exploratory analysis, and building an interactive dashboard to visualize key metrics.

Problem Statement

The objective of this project is to analyze sales data to identify trends, top-performing regions, and product categories.

Tools Used
1) Excel
2) Power BI

Key Insights
1) West region has the highest sales
2) Furniture category generates the highest sales
3) Sales show a fluctuating trend throughout the year, with peaks in April and July
